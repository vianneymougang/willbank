┌──────────────────────────────────────────────────────────────────────────────┐
│                    🔄 FLUX DE NOTIFICATION                                   │
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  1. 👤 Utilisateur effectue une action (créer, modifier, supprimer)         │
│  2. 📡 ApiService traite l'opération (mode mock)                            │
│  3. ✅ Callback de succès est appelé                                        │
│  4. 🔔 NotificationService.addNotification() est appelé                     │
│  5. 📝 Notification ajoutée à la liste                                      │
│  6. 🔴 Badge dans la barre supérieure se met à jour (+1)                    │
│  7. 📋 Panneau de notifications affiche la nouvelle notification            │
│  8. ✨ Animation pulse attire l'attention                                   │
│  9. 🎉 Utilisateur voit le feedback immédiat                                │
